    Class ClipMotion

    Three.js の THREE.AnimationClip を Motion として再生するクラスです。 glTF や BVH から読み込まれたアニメーションデータの再生に使用されます。

    通常は GLTF や Acerola3D が内部で自動的に生成するため、直接インスタンス化する機会は少ないです。
