    Class GLTFMotion

    GLTF用のMotion。 GLTFから取り外しできるが、取り外した時に保持している 情報はTHREE.AnimationClipのみで、他の必要な物は、 GLTFにsetMotion()で取り付けた時に、再構築される。 前提として、3Dモデルが同じBone構造をもっていることが 必要で、取り付け先の3Dモデルが最初からClipを持っていて 同じ名前だったら、そのClipは上書きされて消される。
