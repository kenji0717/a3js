    Class AvatarController2

    コンストラクタで指定されているアバターをキーボードで コントロールするコントローラ。こちらはRigidBodyと avatar.transformer.setLinvel()でコントロールする方。 地面判定が不正確だけど、まわりのRigidBodyから押されたり、 押したりできる。

    RAPIERのCharacter controllerとavatar.transformer.Location()で コントロールする方はAvatarController。
