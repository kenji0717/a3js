    Class A3ObjectAbstract

    シーンの中に配置される全てのオブジェクトのベース となるアブストラクトクラス。シーンの中の表示対象 はもちろん、カメラやライトなどもこのクラスのサブ クラスにしないといけない。特に、このアブストラクト クラスでは、3D空間内での移動や、物理演算に関する 必要なメソッドを実装する。
