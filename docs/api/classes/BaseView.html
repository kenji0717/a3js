    Class BaseView

    View インターフェースの基本実装クラスです。 Canvas などの HTML 要素は BaseView を内部にプロパティとして持ちラッパーとして実装されています。 独自の表示クラスを作る場合は、このクラスを継承するか参考にしてください。
