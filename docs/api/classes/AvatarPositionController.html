    Class AvatarPositionController

    コンストラクタで指定されているアバターをキーボードで コントロールするコントローラ。こちらはRAPIERのCharacter controllerとavatar.transformer.setPosition()でコントロールする方。 地面判定が性格で安定性が高いけれど、まわりのRigidBodyから 押されたり押したりできない。

    RigidBodyとavatar.transformer.setLinearVelocity()でコントロールする方は AvatarVelocityController。
