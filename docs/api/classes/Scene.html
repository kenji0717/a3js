    Class Scene

    3D 仮想空間を管理するクラスです。

    ObjectA3 を追加・削除してシーンを構築します。 毎フレームの更新処理（位置計算・物理シミュレーション・衝突検知）もこのクラスが行います。

    Example

    const scene = new Scene();

    const box = new Box();
    scene.add(box);

    // 毎フレーム呼び出す
    function animate(dt: number) {
      scene.update(dt);
    }
