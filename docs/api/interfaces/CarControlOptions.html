    Interface CarControlOptions

    CarControl の生成オプションです。 車体・タイヤのサイズやサスペンション特性など、車の物理パラメータを設定します。

    タイヤの順番は FL(0)・FR(1)・RL(2)・RR(3) で統一されています。
