# a3js

TypeScript (JavaScript) 3DCG Library

小学生から使いはじめられて、プログラミングが得意な大学生でも
簡単には飽きないレベルの3DCGライブラリを目指しています。

PC、スマホ、タブレット、ヘッドマウントディスプレイ(HMD)に
搭載・インストールされたウェブブラウザ上で動作します。

Three.jsを基盤としており、3Dオブジェクトのモードを切り替える
ことで、物理エンジン(Rapier)を利用したシミュレーションも可能です。

主にプログラミング教育での利用を目的としていますが、3Dアプリの
プロトタイプ作成にも利用できるようにしていきたいと思っています。

まだ、未完成ですが以下のGitHub Pagesでドキュメント公開していきます。
